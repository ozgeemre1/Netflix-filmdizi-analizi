Netflix Veri Analizi Projesi

Bu proje, Kaggle üzerindeki "Netflix Movies and TV Shows" veri setini kullanarak platformdaki içerik trendlerini, ülke dağılımlarını ve tür tercihlerini analiz etmek amacıyla hazırlanmıştır.

📌 Temel Analiz Soruları:

Netflix kütüphanesinde film mi yoksa dizi mi daha ağırlıklı?

İçerik üretiminde hangi ülkeler lider?

Yıllara göre içerik ekleme hızı nasıl değişti?

İçeriklerin yaş gruplarına (rating) göre dağılımı nasıl?

🚀 Kullanılan Teknolojiler:

Python (Pandas, Numpy)

Veri Görselleştirme (Matplotlib, Seaborn)

Jupyter Notebook
